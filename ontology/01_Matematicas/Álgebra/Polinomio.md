## 1. Polinomio Concepto (Polinomio concepto)

### Definición:
Un **polinomio** es una expresión algebraica formada por una suma finita de términos monomiales. Cada término monomial consta de un coeficiente, una variable y un exponente.

### Estructura General:
Un polinomio general en una variable \(x\) se representa de la siguiente manera:

$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_2 x^2 + a_1 x + a_0$


Donde:
- \(n\) es un número entero no negativo (el grado del polinomio).
- \(a_n, a_{n-1}, \dots, a_0\) son coeficientes (números reales o complejos).
- \(x\) es la variable.
- \(a_n \neq 0\) (coeficiente líder no nulo).

---

### Ejemplo:
El siguiente es un ejemplo de un polinomio:

$P(x) = 4x^3 - 2x^2 + 5x - 7$


Elementos:
- Términos: \(4x^3, -2x^2, 5x, -7\)
- Grado: 3 (porque el mayor exponente es 3)

---

## 2. Grado de un Polinomio (Grado de un polinomio)

### Definición:
El **grado** de un polinomio es el mayor exponente de la variable en el polinomio. Se denota como $( \deg(P(x)) )$.

### Casos Especiales:
1. **Polinomio constante**: Si todos los términos son constantes, el grado es 0.
   
   $P(x) = 5 \quad \Rightarrow \quad \deg(P(x)) = 0$

2. **Polinomio nulo**: Si todos los coeficientes son cero, no tiene grado definido.

---

### Ejemplo:

$P(x) = 3x^5 - 4x^3 + 2x^2 - x + 8$

- Términos: \(3x^5, -4x^3, 2x^2, -x, 8\)
- El mayor exponente es 5 → Grado = 5

---

## 3. Factorización de Polinomios (Factorización polinomio)

### ¿Qué es la factorización?
La **factorización de polinomios** es el proceso de expresar un polinomio como el producto de polinomios de menor grado (factores).

### Tipos de Factorización:

#### 1. Factor común:

$P(x) = ax + bx = x(a + b)$

**Ejemplo**:

$6x^2 - 12x = 6x(x - 2)$

#### 2. Factorización de trinomios cuadrados perfectos:

$a^2x^2 + 2abx + b^2 = (ax + b)^2$

**Ejemplo**:

$x^2 + 6x + 9 = (x + 3)^2$

#### 3. Raíz racional:
Si un polinomio tiene raíces racionales, podemos factorizarlo usando el teorema del factor.

**Ejemplo**:

$x^2 - 5x + 6 = (x - 2)(x - 3)$

---

## 4. Identidad Algebraica (Identidad algebraica)

### ¿Qué es una identidad algebraica?
Una **identidad algebraica** es una igualdad que se cumple para todos los valores de las variables involucradas.

### Ejemplos de Identidades Algebraicas:

1. **Identidad de la suma de binomios**:

   $(a + b)^2 = a^2 + 2ab + b^2$

2. **Identidad de la diferencia de binomios**:
   
   $(a - b)^2 = a^2 - 2ab + b^2$

3. **Identidad de la suma y resta de cubos**:
   
   $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$

---

## 5. Práctica con ejemplos

### Ejercicio 1:
Factoriza el siguiente polinomio:

$P(x) = x^2 - 9$

**Solución**:

$P(x) = (x - 3)(x + 3)$

Estos conceptos son la base para resolver ecuaciones, sistemas de ecuaciones y problemas más complejos.
